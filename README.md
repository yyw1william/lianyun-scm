# 链运 SCM · 跨境物流全链路管理系统（可交互原型）

> 面向自营跨境卖家的供应链效率工具：把「选货代 → 比价评分 → 订舱审批 → 在途监控 → 库存管理 → 口碑回流」
> 六个环节串成一条闭环，半自动化决策（系统摆数据 + 给参考分，人拍板）。

## 项目背景

以 Anker C28 扫地机器人品类为示例，自营跨境发货、目标市场美国，链路为
**国内工厂 → 头程（LCL/FCL）→ Amazon AWD 卫星仓 → 自动调拨 → FBA 配送仓 → 消费者**。

真实痛点是：选货代靠 Excel 和人肉比价、报价口径不统一、在途时效靠群里问、库存呆滞事后才发现。
本原型验证的是——**能否用一套系统把这条链路的决策、监控、复盘沉淀下来，并且越用越准**。

## 功能架构（9 个页面）

| 页面 | 模块 | 解决什么 |
|---|---|---|
| P1 | 工作台 | 今日风险与待办总览，所有入口可下钻 |
| P2 | 选型需求 | 定义需求（品类/数量/时效/目的地），AI 语音或粘贴报价单录入 |
| P3 | 货代报价 | 阶梯价表录入，支持增删货代、一单一议特例 |
| P4 | 比价看板 | 横向对比报价/时效/舱位/口碑，真实值 + 悬浮查看计算逻辑 |
| P5 | 评分推荐 | 六维评分卡 + 场景权重（日常/旺季/应急）+ AI 分析结论 |
| P6 | SO 订舱草稿 | 二次确认与风控（截关日、免箱期），生成订舱委托 |
| P7 | 运输监控 | 批次级轨迹时间线、ETA vs 承诺、逾期预警、催办留痕、履约打分 |
| P8 | 库存看板 | 仓库级 → 批次级下钻，库龄分布、呆滞预警、盘点复核 |
| P9 | 货代档案 | 口碑沉淀（来自 P7 打分回流），历史履约与价格记录 |

## 三个核心设计

1. **场景化权重模板**：内置「日常 / 旺季 / 应急」三套权重，旺季前把「舱位保障」权重从 15% 拉到 30%。
2. **口碑数据闭环**：每票货履约完成后在 P7 打分 → 回流 P9 货代档案 → 成为下一轮选型的评分依据。
3. **全链路深链下钻**：工作台任意卡片/待办/批次行 → 直接定位到目标页面的具体仓库或批次（自动展开 + 高亮）。

## 技术说明

- 形态：**单文件可交互原型**（`mockup/APP.html`，约 390KB，内嵌 9 页 + CSS + JS，零外部依赖）
- 外壳用 iframe `srcdoc` 承载各页，通过 `shellGo` 统一接管页内跳转与深链（`#awd` / `#BATCH-2608-001`）
- 数据：浏览器 `localStorage` 持久化，前面页面录入的内容会驱动后续页面变化，右上角可重置演示数据
- 移动端：已做响应式适配
